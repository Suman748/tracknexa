# SKS TrackNexa

Live vehicle tracking website for fleets in Tamil Nadu. See every vehicle on a map, check delays, and view arrival times.

## Live website

**https://suman748.github.io/tracknexa/**

[Open SKS TrackNexa](https://suman748.github.io/tracknexa/)

## Try the demo

Search for **SKS TrackNexa**, open the site and click **Try demo**. No sign-up is needed.

## What it includes

- Home page that explains what TrackNexa is and how it works
- Sign up, sign in and forgot password pages
- Dashboard with active vehicles, delayed vehicles, distance, average speed, a vehicle table and a weekly trips chart
- Live tracking page with a Tamil Nadu map, moving vehicles, speed, remaining distance and ETA
- Tracking-themed highway background
- Works on phones and computers, in light and dark mode

## How to run

**Online:** open the live website link above.

**On your computer:**
1. Download or clone this repository.
2. Keep `index.html` and `script.js` in the same folder, then open `index.html` in any web browser.

No install or build step is needed.

## Demo notes

- Vehicles on the map are simulated, not real GPS data.
- Accounts are saved only in the visitor's own browser, so they are not shared between devices.
- The map is a drawn outline of Tamil Nadu, not a street map.
